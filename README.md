## 🚀 Featured Project

<table>
  <tr>
    <td width="55%">
      <h3>Your Download Manager (YDM)</h3>
      <p>The fast, open-source, all-in-one download manager for Windows — with macOS and Linux support upcoming.</p>
      <ul>
        <li>⚡ <strong>Segmented HTTP/FTP</strong> downloads via aria2</li>
        <li>🧲 <strong>BitTorrent</strong> with DHT via librqbit</li>
        <li>🎬 <strong>HLS/M3U8 streams</strong> via FFmpeg</li>
        <li>🌐 <strong>Site video extraction</strong> (YouTube, Vimeo, Twitch, and more) via yt-dlp</li>
        <li>🖱️ <strong>One-click browser handoff</strong> — a Manifest V3 extension for Chrome, Edge, and Firefox</li>
      </ul>

## 🛠️ What I'm Working On

- ⚙️ **YDM core engine work** — segmented downloads, BitTorrent, HLS, and site extraction in one clean interface
- 🔌 **Browser integration** — a Manifest V3 extension that hands downloads off to YDM with one click
- 💻 **Cross-platform releases** — packaging YDM for macOS and Linux alongside Windows, with a CI matrix covering every target
- 📚 **Continuous learning** — deepening my Rust, Tauri, and systems-level engineering skills with every release
