## Featured Project

### Your Download Manager (YDM)

A fast, open-source, all-in-one download manager for Windows, with macOS and Linux support upcoming.

Segmented HTTP/FTP downloads (aria2) · BitTorrent with DHT (librqbit) · HLS/M3U8 streams (FFmpeg) · site video extraction (yt-dlp) — plus a Manifest V3 browser extension that hands downloads off to YDM with one click.
