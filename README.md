## 🛠️ What I'm Working On

- ⚙️ **YDM core engine work** — segmented downloads, BitTorrent, HLS, and site extraction in one clean interface
- 🔌 **Browser integration** — a Manifest V3 extension that hands downloads off to YDM with one click
- 💻 **Cross-platform releases** — packaging YDM for macOS and Linux alongside Windows, with a CI matrix covering every target
- 📚 **Continuous learning** — deepening my Rust, Tauri, and systems-level engineering skills with every release
