### 🔥 Selected work

> Everything below is real code from `D:/Projects` → GitHub. No mockups.

**🖥️ Your Download Manager (YDM)** `Tauri 2 · Rust · Svelte 5 · aria2 · libtorrent · FFmpeg`
<br/>My flagship. A private, all-in-one download manager for Windows (macOS/Linux next) — segmented HTTP/FTP, BitTorrent, HLS streams, YouTube/Twitch/Vimeo extraction, one-click browser handoff. Zero telemetry by design.
<br/>→ *In private testing, open-sourcing soon — [follow me to catch the release](https://github.com/tamimlabs)*

**🧠 NexusMind AI** `Python · Gemini · Google ADK · Cloud Run` — [code](https://github.com/tamimlabs/nexusmind-ai) · [demo](https://youtu.be/57qWqvspqjs)
<br/>One sentence in → planned, executed, self-corrected task run out. Google "All Things Agentic" hackathon build.

**👁️ Imotion Detector** `Python · OpenCV · DeepFace · FER` — [code](https://github.com/tamimlabs/Imotion-detector)
<br/>Real-time facial emotion detection with 3 swappable engines so you can trade accuracy for speed.

**🎬 Social Media Automation** `Python · n8n · Gemini · MoviePy` — [code](https://github.com/tamimlabs/social-media-automation)
<br/>Zero-cost pipeline: raw video + prompt → captioned 9:16 clip, auto-edited, auto-published via Telegram + n8n.

**⚔️ Cyber Clash 2077** `HTML · CSS · JS` — [🎮 play it](https://cyber-clash-2077.pages.dev/)
<br/>50-level cyberpunk browser fighter, 5 story arcs, 5 bosses. Zero backend, pure front-end juice.

**🔌 Browser Download Companion** `JS · Manifest V3`
<br/>The browser half of YDM — Chrome / Edge / Firefox → one click sends any download to YDM.

**🤖 PID Line-Follower Robot** `Arduino C++ · U8g2 · EEPROM`
<br/>Nano + L298N + 14× TCRT sensors through a 16-ch mux + OLED menu + EEPROM-tuned PID. `robot_code_v1/v2.ino` — real hardware, real tuning pain.

**🎞️ STICK: A Stickman Epic** `Python · MoviePy · FFmpeg`
<br/>CLI movie studio — scripted scenes render to video, a full soundtrack gets synthesized, then muxed into a final MP4.

**🌐 tamimlabs.pages.dev** `Vanilla HTML/CSS/JS` — [visit](https://tamimlabs.pages.dev)
<br/>My portfolio is itself a project: sorting visualizer, canvas particle lab, triple-format live clock, in-browser terminal. No frameworks were harmed.
